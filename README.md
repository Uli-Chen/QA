# iGEM Wiki Crawler and QA Generation by LLM

This repository contains a set of scripts for crawling iGEM team information from the official wiki, filtering relevant teams, and generating question-answer (QA) pairs using large language models (LLMs). It is designed to support automated knowledge extraction and QA dataset creation for synthetic biology projects.

## Repository Structure

### `QAbyLLM.py`
**Description:**  
Generates question-answer pairs based on the crawled wiki data using an LLM.

**Usage:**  
python QAbyLLM.py --input_file "your_crawled_wiki_data_path" --output "LLM_QA_pair_output_path" --api-key "your_api_key" --qa-pairs "number_of_qa_piars_for_one_wiki"
---

### `team_filter.py`
**Description:**  
Filters the list of teams based on specific criteria (e.g., by year).
---

### `teams.csv`
**Description:**  
Contains the FULL LIST of basic metadata of iGEM teams, such as team names, years(2014 to 2025), and wiki URLs.
---

### `teams_wiki_data.json`
**Description:**  
Stores the crawled wiki content for each team in JSON format.

**Usage:**  
Generated by `wiki_crawler.py` and consumed by `QAbyLLM.py`.
---

### `wiki_crawler.py`
**Description:**  
Scrapes wiki pages of iGEM teams and extracts wetlab content(currently 'Experiment' and 'Proposal') for further analysis or QA generation.
